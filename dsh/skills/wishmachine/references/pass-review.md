# 通读清单（正文写完必做一遍）

这是**问题类型清单**，不是词表。它不预设句子长什么样，只问"这句话站不站得住"——所以它能覆盖
所有搭配错误，而不是只盯着某几个词。

顺序：正文写完 → **本清单通读** → 定点改写 → `check --profile style` / `audit`。

## 1. 搭配：这个动词能配这个名词吗

问法：把这句话改说成一个事实（谁做了什么、谁会怎样），还成立吗？复述不出来的，就是搭配错。

- ❌ `名字不死，活人就得死。` —— 名字不能死，"死"只能配人/动物/植物。
- ✅ `死的是登记页上那一栏。人还活着，名字注销了。`

同类高发：抽象名词（规矩、记忆、证据、程序、时间、真相、身份、编号）配上生命动词（死、活、流血、
呼吸、疼、醒、哭）。**注意只报可疑，不要整批替换**——`证据链断了`、`编号断开` 都是对的。

## 2. 前后一致：前文立下的状态，后文还记得吗

问法：开头停下的东西后面又动了吗？拿走的东西又出现了吗？说定的事被悄悄改了吗？

- ❌ 开头 `排风扇停了` → 结尾 `挂钟的走针声压过了排风扇`（没人开过它）
- 也查：谁说过的话被推翻、谁拿着的物件凭空换了手、天气/光线突然变了。

## 3. 空间：这个人在哪，这个房间有什么

问法：这个房间有窗吗？在哪一层？从这里走到那里要多久？他够得着吗？

- ❌ 地下停尸房 `窗外有救护车掠过，蓝光扫过一排空柜`
- 也查：隔着门能不能看见、隔着玻璃能不能听见、柜子在墙边还是屋子中间。

## 4. 时间：钟点能不能接上

问法：把全章钟点列出来，按序读一遍。

- 检查：有没有倒流、两件事之间的时距合不合理、作息常识（凌晨三点这号人该在不在岗）。
- 一项常见毛病：全章报时太密（三点四十七、四点零三、四点零六…），读起来像打卡。**两个锚点足够**。

## 5. 在场与知情：他当时在场吗，他凭什么知道

问法：这件事发生时这个人在不在？他说的这句话，他从哪儿知道的？

- ❌ 两拨人分开之后，一个视点写出另一拨屋里的动静。
- ❌ 角色说出只有读者（或作者）才知道的结论。

## 6. 可数：读者会去数的，必须对

问法：凡是出现"三样东西""第几个""两个人"，读者会去数。

- 上一章出现过：`就三个字：深处置物，险`（实为五字）、`给了三样东西` 后文只列两样、
  `四个人` 但队形五人、`第三张` 但上文只对上两张。

## 输出格式

按类逐条报，一条一行：

```
[3 空间] 第 83 段：「窗外有救护车掠过，蓝光扫过一排空柜」
         这一章停尸房没交代有窗，且人在盯柜子，蓝光扫过一排柜等于窗对着墙。
         建议：改成走廊那头的门缝/值班室窗，或删掉这个蓝光。
```

要求：
- **不确定就标「可疑」，不要改**；只有确认矛盾才给改法。
- 每类都要真的过一遍，没有就写"本类无"。
- 不许为了凑数编问题——报错了比不报更坏，作者会去改本来对的地方。
