# 场景焦点与母题预算

“老数数”“无关紧要的描述太多”通常不是句子问题，而是**场景没有目标/转折**、**母题没有预算**：

- 设定把“数垄/数六/数七”当核心悬念，模型就会每章都数一遍；
- 章节目标字数 2600，重写后写到 3300–3600，多出来的部分往往是重复的仪式动作和感官细节；
- 每个动作都写（抹纸边、蹭裤腿、笑一下、看很久），但没有改变任何状态。

## 1. 每场戏四件事

写之前先回答，写不进正文也要在脑子里有：

1. **目标**：这一场谁想要什么？具体到“拿到/阻止/确认”一件事。
2. **阻碍**：谁或什么在挡？不能是“气氛”。
3. **转折**：这场结束时，什么变了？（信息、关系、代价、位置、时间）
4. **结果**：主角下一步因此做什么？

如果一场戏删掉后，下一场完全不受影响，它就是可删的。

## 2. 每个段落至少做一件事

允许的段落功能只有：推进动作、揭示信息、改变关系、付出代价、制造悬念。
连续两段只是“环境/仪式/回忆”而没有新信息，就合并或删掉。

检查器能给的代理指标：

```bash
wishmachine check --dir <project> --profile style --target chapter --id P1-V1-C1
```

- `style.chapter.padding`：章节长度超过 target 10%/25%，提示注水
- `style.chapter.motif_overuse`：`novel.json.style.motifs` 里的母题词密度过高
- `style.chapter.dialogue_balance`：对话比例过低
- `style.chapter.simile_density` / `template_connectors`：描写/模板句过密

## 3. 母题预算

在 `novel.json` 里声明本书的核心母题：

```json
{
  "style": {
    "motifs": ["数", "手指", "六", "第七垄", "纸边", "账"],
    "chapter": {
      "motifMaxPer1k": { "warn": 3, "risk": 6 },
      "paddingRatio": { "warn": 1.1, "risk": 1.25 }
    }
  }
}
```

规则：

- 同一母题全书出现 **3 次以内**是母题；超过就是口头禅。
- 每次重复必须**升级**：第一次是确认，第二次要多数出一垄，第三次要付出代价/改变认知。
- 纯仪式性重复（再数一遍、再抹一次纸边、再蹭一次裤腿）直接删。
- `audit --profile style` 会跨章检测重复的 4–6 字短语（`style.book.repeated_motif`），
  列出出现在 ≥40% 章节的描写/动作短语。

## 4. “数数”场景怎么改

- ❌ 她数了一遍。六垄。又数了一遍，还是六垄。手指在裤腿上蹭了蹭。
- ✅ 她数了一遍，六条。东头第三家的垄背上多出一道新土，像有人半夜翻过；她没再数第二遍，
  先把那截土记进账，账脚写“未动”。
  （第二遍不是重复确认，而是发现新信息；手指动作删掉，换成可记账的变化。）

## 5. 删减顺序

1. 删不改变状态的段落（重复仪式、环境特写、回忆插叙）。
2. 合并同一功能的段落（两个“看很久”只留一个）。
3. 把母题重复改成一次升级（数→发现多一垄→数出第七垄要付代价）。
4. 最后才润色句子；先保证每场有转折。
